How Invite Links Work
1
Teacher generates a unique invite link from this panel and shares it with students via chat, email, or any messaging app.
2
Each link contains a cryptographic token with the session code and an expiry timestamp baked in — it cannot be altered.
3
The link expires automatically after 30 days (or the chosen duration). Expired links redirect to an "Access Expired" page — no one can join.
4
The teacher can revoke any link at any time from the Active Links table above, immediately blocking all future use.
5
Each link is single-session only — once expired or revoked, it can never be reactivated. A new link must be generated for the next class.
